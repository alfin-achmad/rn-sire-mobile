# SIRE Mobile App

Aplikasi **SIRE Mobile** adalah platform berbasis Android yang dirancang untuk mendukung proses **aktualisasi dan registrasi elektor** secara digital di **Timor Leste**. Aplikasi ini memfasilitasi petugas lapangan untuk mengumpulkan, memverifikasi, dan memperbarui data elektor secara **real-time** langsung dari perangkat mobile.
